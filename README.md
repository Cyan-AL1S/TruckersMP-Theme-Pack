## 安装

详细图文教程见：

- [中文安装教程](./ReadME-ChineseSimplyed.md)
- [English Installation Guide](./ReadME-English.md)

### 快速说明

**旧版启动器：**
1. 解压下载的压缩包
2. 把文件复制到 `C:\ProgramData\TruckersMP\data`
3. 启动游戏

**新版启动器：**
1. 解压压缩包
2. 启动器设置里找到安装路径，把文件放进去
3. 打开 `data` 文件夹再复制一份
4. 启动游戏

# TruckersMP Theme Pack

A UI theme pack for TruckersMP that gives your game a fresh look — yes, the in-game plugin interface too.

---

## Features

- Supports both ATS (American Truck Simulator) and ETS2 (Euro Truck Simulator 2)
- Modular design: base package + separate mods, pick what you need
- Works with both old and new TruckersMP launchers
- **China Qiyuan - Wabi-Sabi Public Edition** now available as an exe installer

---

## Download

Head over to [Releases](https://github.com/你的用户名/TruckersMP-Theme-Pack/releases) to grab the latest version.

Two formats:

- `exe` installer — one-click setup (recommended)
- `zip` archive — manual installation

---

## Installation

Detailed guides:

- [中文安装教程](./ReadME-ChineseSimplyed.md)
- [English Installation Guide](./ReadME-English.md)

**Quick start for the old launcher:**
1. Extract the downloaded archive
2. Copy files into `C:\ProgramData\TruckersMP\data`
3. Launch the game

**Quick start for the new launcher:**
1. Extract the archive
2. Open launcher Settings, locate the install path, and paste files there
3. Also copy files into the `data` folder
4. Launch the game
