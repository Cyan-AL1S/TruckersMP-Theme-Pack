# TruckersMP Theme Pack

A UI theme pack for TruckersMP that gives your game a fresh look — yes, the in-game plugin interface too.

---

## Features

- Supports both ATS (American Truck Simulator) and ETS2 (Euro Truck Simulator 2)
- Modular design: base package + separate mods, pick what you need
- Works with both old and new TruckersMP launchers
- **China Origin Team - Wabi-Sabi Public Edition** now available as an exe installer

---

## Download

Head over to [Releases](https://github.com/Cyan-AL1S/TruckersMP-Theme-Pack/releases) to grab the latest version.

Two formats:

- `exe` installer — one-click setup (recommended)
- `zip` archive — manual installation
